# העוגות של הודיה 🎂

אתר לעוגות של הודיה לוי שאבי, גבעת שמואל. אתר סטטי (HTML/CSS/JS, בלי build).

## מה יש באתר
- **פתיחה עם עוגה מצוירת**: לוחצים על הלהבות, מכבים את הנרות ומקבלים קונפטי.
- **מה חוגגים**: ארבעה סוגי עוגות עם מחירי התחלה.
- **סטודיו לבניית עוגה**: סרגל "כמה אורחים" שממליץ על גודל, בחירת סוג, גודל ותוספות, והערכת מחיר חיה. ההזמנה נשלחת להודיה כהודעת וואטסאפ מוכנה.
- **גלריה**: 44 עוגות עם סינון לפי קטגוריה ותצוגה מוגדלת (החלקה בנייד). כפתור "אני רוצה כזאת!" שולח את העוגה בוואטסאפ.
- מה כלול, תוספות, איך מזמינים, כפתור וואטסאפ צף.

## עדכון תוכן
- מחירים, גדלים, תוספות, טלפון: `js/data.js`
- עוגות בגלריה: `js/gallery-data.js`, והתמונה עצמה ב־`assets/gallery/`
- אחרי שינוי ב־`css/` או `js/` מעלים את `?v=` ב־`index.html`.
