# Bloomy Flower Studio 🌸

אתר הזמנות לזרים של Bloomy מכפר מסריק — משלוחים לחיפה, נהריה והקריות.

אתר סטטי (HTML/CSS/JS בלבד, בלי build). פותחים את `index.html` או מעלים את התיקייה לכל אחסון סטטי (GitHub Pages, Netlify, Vercel).

## מבנה
- `index.html` — כל העמוד
- `css/style.css` — עיצוב, מצב כהה, רספונסיביות
- `js/data.js` — **כל התוכן העסקי**: זרים, מחירים, פרחים לבנייה, ערים, שאלות נפוצות, מספר וואטסאפ
- `js/bloom3d.js` — הזר התלת־ממדי בראש העמוד (Three.js, נטען מ־`vendor/`)
- `js/fx.js` — אנימציות ואפקטים
- `js/store.js` — קטלוג, סינון, מועדפים, גלריה, סל
- `build.html` + `js/build.js` + `css/build.css` — עמוד הסטודיו לבניית זר (מסך אחד, 3 שלבים)
- `js/flora3d.js` — מודלים תלת־ממדיים לזר בעמוד הראשי ולוורד בעמוד ההגרלה
- `js/bouquet2d.js` — ההדמיה בסטודיו: תמונות פרחים אמיתיות מסודרות בזר עם עומק ועטיפה
- `js/surprise.js` — ההפתעה בזר הפתיחה וקוד ההנחה BLOOMY10
- `js/checkout.js` — הסל וההזמנה (משלוח/איסוף, תאריך, ברכה, תשלום → וואטסאפ)
- `vendor/three.min.js` — ספריית Three.js r128
- `assets/` — תמונות הזרים והפרחים

## עדכון מחירים / זרים
עורכים את `js/data.js` בלבד. תמונה חדשה לזר: שמים קובץ `webp` ב־`assets/photos/` ומפנים אליו בשדה `img`.

## עדכון גרסה
אחרי שינוי בקבצי `css/` או `js/`, מעלים את המספר ב־`?v=` בקישורים שב־`index.html`, כדי שהדפדפנים יטענו את הקבצים החדשים.
